# WorldFIP 协议包 — 需 WorldFIP/Fipio 总线接口桥接

> [English](README.en.md)

WorldFIP (Factory Instrumentation Protocol) 现场总线协议。需要 WorldFIP 总线接口，通过内核 Bridge 层桥接。

## 安装

```bash
composer require erikwang2013/industrial-protocols-worldfip
```

## 功能

WorldFIP 桥接、BridgeConnector 连接管理

## 所需硬件

WorldFIP/Fipio 总线接口

## 兼容框架

Laravel / Webman / Hyperf / ThinkPHP / Yii2 / Yii3 / Plain PHP

## 系统要求

- PHP >= 8.1
- WorldFIP 接口
- erikwang2013/industrial-protocols-kernel
